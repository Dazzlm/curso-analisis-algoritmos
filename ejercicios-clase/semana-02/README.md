# Laboratorio 02 — Configuración del entorno

Se creó el entorno virtual desde la raíz del repositorio con `python3 -m venv venv`.
En Windows se activó con `venv\Scripts\activate`.
Se verificó que el entorno estuviera activo comprobando el prefijo `(venv)` en la terminal.
Se instaló la dependencia `matplotlib` con `pip install matplotlib`.
Se generó el archivo de dependencias con `pip freeze > requirements.txt`.
Para reproducir el entorno, se debe crear nuevamente el entorno con `python3 -m venv venv`.
Luego se activa el entorno con `venv\Scripts\activate`.
Finalmente, se instalan las dependencias con `pip install -r requirements.txt`.
