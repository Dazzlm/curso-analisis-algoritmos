# Curso Análisis de Algoritmos

Repositorio utilizado para el desarrollo de los laboratorios, ejercicios y actividades del curso **Análisis de Algoritmos** durante el semestre 2026-2.

## Estructura del repositorio

Este repositorio está organizado de la siguiente manera:

- **laboratorios/**: Contendrá los cinco laboratorios evaluativos desarrollados durante el semestre.
- **ejercicios-clase/**: Almacena los ejercicios prácticos realizados en las sesiones de clase.
- **benchmarks/**: Contiene scripts y herramientas para medir el rendimiento y comparar algoritmos.

## Guía de uso

Para clonar el repositorio y comenzar a trabajar:

```bash
git clone https://github.com/Dazzlm/curso-analisis-algoritmos.git
cd curso-analisis-algoritmos
git status
```

Cada laboratorio deberá desarrollarse dentro de la carpeta `laboratorios/`, manteniendo un historial de cambios mediante Git y sincronizando el repositorio con GitHub después de cada avance importante.
